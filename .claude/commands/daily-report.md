# Daily Report

Run the daily report script and present the results.

## Instructions

1. Run `npx tsx scripts/daily-report.ts $ARGUMENTS` (defaults to yesterday if no args)
   - Supports `--date=YYYY-MM-DD` for a specific date
   - Supports `--days=N` for a multi-day summary
2. Present the output directly — don't summarize or reformat it
3. After the report, offer 1-2 brief observations about anything notable (big drops, spikes, interesting patterns)
